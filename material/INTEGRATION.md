# Запуск общей сборки · 0.5

Материалы, готовность и AI-сводка работают в одном API и очереди. Настройка GigaChat описана в [GIGACHAT_SETUP.md](GIGACHAT_SETUP.md), контракт материала — в [MATERIAL_API.md](MATERIAL_API.md).

В версии 0.5 добавлен [предварительный расчёт стоимости постройки](VALUATION.md): демонстрационные тарифы, три суммы в карточке, ручные параметры и история расчётов. Он выполняется локально, без отдельной модели или внешнего API. GigaChat получает готовые суммы для пояснения.

Из корня проекта, в отдельных терминалах:

```powershell
# API
.\.venv\Scripts\python.exe -m uvicorn api.main:app --host 127.0.0.1 --port 8000
```

```powershell
# Воркер: фотографии и AI-сводки
.\.venv\Scripts\python.exe -m worker
```

```powershell
# Фронт с прокси на API
$env:API_TARGET = "http://127.0.0.1:8000"
node front/server.mjs
```

Откройте `http://127.0.0.1:4173`; в «Подключение и профиль» выберите режим API. В режиме «Демо» фронт использует собственные синтетические данные.

Настройки в `.env` читаются при запуске API и воркера; переменные окружения имеют приоритет. По умолчанию `MOCK=1`: снимки и правки действительно сохраняются, модели недоступны, внешние запросы GigaChat не выполняются. Для подключения готового детектора используйте `MOCK=0`, `DETECTOR_FACTORY=agents.readiness.yolo:create_detector`, `READINESS_WEIGHTS=путь_к_локальным_весам`. Материальная модель подключается отдельно через `MATERIAL_MODEL_FACTORY=module:factory`.

Классы детектора совпадают с текущим ML-набором: 13 значений в `configs/classes.yaml`, `paving` имеет номер 11, `fence` — 12. Детектор вызывается один раз на снимок; новый классификатор материала использует найденные стены. Готовность работает без классификатора, но ему нужен работающий детектор стен. Проверки материала и готовности разделены; исходные ответы моделей сохраняются. Веса, параметры 1280/384, формат результата и ограничения выбора участка — в [YOLO_INTEGRATION.md](YOLO_INTEGRATION.md).

`GET /api/v1/meta` сообщает доступные функции, включая `valuation: true`. Полный банковский риск, дирижёр, задачи, тревоги, импорт и анализ участка пока не включены. Расчёт стоимости постройки не оценивает рыночную стоимость или залог. Галерея показывает все файлы, флаг `target_confirmed` задаёт сотрудник. Автоматически вычисленная сторона фасада выдаётся только как `suggested_view`.

Проверки: `python -m pytest -q`, `python -m ruff check api agents integrations schemas worker tests`, `npm.cmd --prefix front test`, `npm.cmd --prefix front run test:integration`. Сквозной тест запускает свои процессы на свободных портах с отдельной базой, использует Chrome и останавливает процессы после проверки.
