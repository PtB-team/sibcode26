# ML: детектор агента готовности

Разметка снимков `dataset/` под YOLO-детектор (классы — `configs/classes.yaml`, BACKEND.md раздел 3.2), обмен с Label Studio и обучение.

```
ml/
├── annotations/
│   ├── labels/<объект>/<снимок>.txt   # разметка YOLO: class cx cy w h (доли кадра)
│   ├── manifest.csv                   # снимок, объект, ракурс, EXIF, число рамок, заметка
│   ├── labelstudio_config.xml         # интерфейс разметки
│   └── labelstudio_tasks.json         # задачи с разметкой для импорта
├── common.py
├── labelstudio.py                     # YOLO <-> Label Studio
├── prepare_dataset.py                 # data/yolo/ с делением train/val по объектам
└── train.py                           # обучение
```

## Обучение

```bash
pip install -r req.txt
python ml/train.py                 # YOLO26m, imgsz 1280, batch 2, 150 эпох, val = объекты 6 и 13
python ml/train.py --batch 8       # на видеокарте от 12 ГБ
python ml/train.py --model yolo11m.pt
```

На RTX 4050 6 ГБ: batch 2 занимает около 5 ГБ, эпоха идёт около 20 с, 150 эпох — около 50 минут.

Скрипт пересобирает `data/yolo/` из разметки, обучает, копирует лучшие веса в `weights/readiness_<модель>.pt` и пишет метрики val в `runs/<name>/metrics_val.json`. `data/`, `weights/` и `runs/` — в `.gitignore`.

Train и val делятся **по объектам** (папкам `dataset/`), а не по снимкам. По умолчанию val — объекты 6 и 13 (готовые дома с окнами). Ранние стадии (фундамент, стены) есть только у объектов 7 и 8, поэтому они целиком в train. Состав меняется флагом `--val-objects`.

## Разметка

72 снимка, 12 объектов, 538 рамок, 12 классов.

| Объект | Снимков | Что на снимках |
|---|---|---|

| 2 | 6 | дом готов: кровля, окна, отделка панелями |
| 3 | 1 | пустой участок, работ нет (снимок без рамок) |
| 4 | 6 | дом готов |
| 6 | 5 | газобетон: кровля, окна, без отделки |
| 7 | 6 | фундамент и первые ряды стен, котлован |

Классы `outbuilding` и `fence` из BACKEND.md (раздел 3.2) убраны из разметки, поэтому `paving` имеет id 11, а не 13.

Правила разметки:
- Размечено всё видимое, включая соседние дома, если они не мелкие. Маска «класс × ракурс» применяется при агрегации (раздел 3.1), а не при разметке: кровля размечена и на надирах, `building` и `paving` — на обоих надирах.
- Фундамент размечается, только пока он открыт (стадия «Фундамент»). Под готовыми домами цоколь не размечается.
- `facade_finish` — сайдинг, штукатурка, панели, облицовка. Мембрана, OSB и открытый газобетон отделкой не считаются.
- Ракурс в `manifest.csv` взят из EXIF: наклон гимбала около −90° — надир (`top_high` или `top_low` по высоте и охвату кадра). Сторона фасада противоположна азимуту камеры: камера смотрит на север — снят южный фасад.

Ограничения, которые надо закрыть до пилота:
- **`roof_frame` (стропила без покрытия) в датасете нет ни одного примера**, `walls_partial` есть только у объекта 7, `door_installed` — 7 рамок. Модель эти классы не выучит, нужны дополнительные облёты на этих стадиях.
- Рамки ставились по превью с координатной сеткой: у крупных элементов точность около 1% кадра, у мелких окон на дальних домах — хуже. Перед финальным обучением стоит пройти разметку в Label Studio.
- Объект 12 (супермаркет) не ИЖС. Исключить: `--exclude-objects 12`.
- Снимки 0007/0008 и 0009/0010 объекта 8, а также 0005/0006 объекта 12 — почти дубли (2 секунды разницы).

## Label Studio

1. Запустить Label Studio с доступом к файлам репозитория:
   ```powershell
   $env:LABEL_STUDIO_LOCAL_FILES_SERVING_ENABLED = "true"
   $env:LABEL_STUDIO_LOCAL_FILES_DOCUMENT_ROOT = "C:\путь\к\sibcode26"
   label-studio start
   ```
2. Создать проект, в Settings → Labeling Interface → Code вставить `ml/annotations/labelstudio_config.xml`.
3. Settings → Cloud Storage → Add Source Storage → Local files, путь `C:\путь\к\sibcode26\dataset`. Синхронизировать **не нужно**: задачи придут из JSON.
4. Import → `ml/annotations/labelstudio_tasks.json`. Рамки придут как готовые аннотации. Флаг `python ml/labelstudio.py export --as-predictions` кладёт их в predictions, то есть как предразметку на проверку.
5. После правок: Export → JSON, затем
   ```bash
   python ml/labelstudio.py import путь/к/export.json
   ```
   Разметка в `annotations/labels/` и ракурсы в `manifest.csv` обновятся, после этого можно запускать `train.py`.

Если классы в `configs/classes.yaml` поменялись, пересоздать файлы: `python ml/labelstudio.py config` и `python ml/labelstudio.py export`.
